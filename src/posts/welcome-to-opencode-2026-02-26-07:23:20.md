# Welcome to opencode

opencode is an interactive CLI (command-line interface) tool designed to help developers with software engineering tasks through natural language conversation.

## What is opencode?

opencode acts as your AI-powered coding assistant, running directly in your terminal. Instead of switching between multiple applications or searching through documentation, you can simply describe what you want to accomplish, and opencode will help you get it done.

## Key Features

- **Natural Language Interface**: Describe your task in plain English and opencode understands
- **File Operations**: Read, write, edit, and search through your codebase
- **Terminal Commands**: Execute bash commands safely and efficiently
- **Web Integration**: Fetch web content and search for information
- **Task Management**: Break down complex tasks into manageable steps
- **Git Operations**: Handle commits, branches, and pull requests
- **Multiple Agents**: Deploy specialized agents for different types of work

## How It Works

opencode uses a collection of specialized tools to accomplish your requests:

1. **Read/Write Files**: Access and modify files in your project
2. **Search**: Find code patterns, files, and content across your codebase
3. **Bash**: Execute terminal commands with proper security measures
4. **Task**: Launch specialized agents for complex, multi-step tasks
5. **Web**: Fetch web content and perform searches
6. **Question**: Gather user preferences during execution

## Getting Started

Start opencode by running it in your terminal. The tool will prompt you to select a skill or enter a command. Some useful skills include:

- **frontend-design**: Create distinctive, production-grade frontend interfaces
- **blog-post-creation**: Create new blog posts with proper structure
- **vercel-react-best-practices**: React and Next.js performance optimization

## Best Practices

- Be specific about what you want to accomplish
- Provide context about your project when needed
- Review changes before committing to files
- Use the task tool for complex, multi-step operations

## Why opencode?

Traditional coding assistants often require context switching between chat interfaces and your code editor. opencode bridges this gap by bringing AI assistance directly into your terminal workflow, allowing you to stay in your preferred development environment while getting intelligent help.

Whether you're debugging an issue, implementing a new feature, refactoring code, or exploring a codebase, opencode is here to help you work more efficiently.

Happy coding!
