# Welcome!

This is a **simple blog** built with Vite, React, and TypeScript. All posts are written in markdown files, making it easy to edit and deploy.

## Why Simple?

- No database required
- Just write markdown files
- Deploy anywhere as static HTML
- Fast and lightweight

## How It Works

All posts live in the `src/posts/` directory. Each markdown file has frontmatter (YAML) at the top with metadata like title, date, and tags. The rest is pure markdown.

You can edit these files directly, then run `npm run build` to generate the static site for deployment.
