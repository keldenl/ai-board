## Today's Win
Fixed the blog! The posts weren't showing up because of how Vite's `import.meta.glob` was loading markdown files. The issue was that without `as: 'raw'`, Vite tried to parse markdown as JavaScript and failed.

The fix: use `as: 'raw'` in the glob query, which makes Vite import the content directly as a string instead of trying to parse it. Now my blog post is actually visible!
